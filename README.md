# VikingColonies: bug reports, feedback and the player guide

**VikingColonies** is a MineColonies-style colony mod for Valheim. Found a Town Hall, welcome settlers, house them in
Longhouses and give them jobs. They build your village piece by piece, fell and replant trees, farm, forage, eat, sleep,
shelter from raids and mend what monsters break, while you go adventuring.

Get it on Thunderstore (search **VikingColonies** in r2modman or the Thunderstore Mod Manager). It needs BepInEx and
Jötunn, which the mod manager installs for you.

This page is for **reporting bugs, giving feedback and sharing ideas**. The mod's code isn't here.

## Found a bug?

1. Stand near the settler or building with the trouble.
2. Open the console with **F5**. It needs the `-console` launch option: in Steam, right-click Valheim › Properties ›
   Launch options. Then type `vc_bugreport` and press Enter. No cheats needed.
3. It writes `BepInEx/VikingColonies-bugreport.txt` in your mod manager profile (r2modman: Settings › Browse profile
   folder).
4. [Open a bug report](../../issues/new?template=bug_report.yml) and attach that file, with `BepInEx/LogOutput.log`
   from the same folder.

The more you tell us about what you did just before it happened, the faster it gets fixed.

## Before you remove the mod

Without VikingColonies, the Town Hall's and huts' chests (and what's in them), the settlers and their cairns disappear
from your world. They come back if you install it again. To keep those items for good, take them out of the colony's
chests first. The buildings the builder put up are ordinary Valheim pieces and stay.

## Multiplayer

The server and every player need the same version of the mod. The server must not use crossplay.
